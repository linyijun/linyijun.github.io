A significant amount of data now contains location and time information, either explicitly (e.g., traffic sensors, air quality sensors, satellite imagery, and GPS trajectories) or implicitly (e.g., images, text documents, and social media). Understanding where events occur and how they evolve across space and time is the key to understanding complex environmental phenomena and human-environmental interactions.

Prerequisites

The students should have good knowledge in applied machine learning (e.g., can select an appropriate machine learning model for solving a problem at hand) and databases (e.g., can write SQL queries with the help of the internet/AI tools) and programming skills. Some background in handling spatial data is a plus but not required.

Learning Outcomes

Students will identify the role of spatial data and the challenges in using them to solve real-world problems. They will define problem scope by selecting appropriate machine learning and data mining technologies, then leverage unique spatial data properties to solve the problem.

For example, students will learn how to find and integrate spatial data from heterogeneous sources, then build machine learning methods for descriptive and predictive analysis.
